## 2. 소유자 결정 (진영, 2026-10-03/04)

1. **UNKNOWN 하위펀드는 거부**한다(차감+플래그 안 함). 노출 0원 UNKNOWN은 데이터 오류로 거부하며 `DEMO_RULE_V2`에 반영됐다(PR #32). `DEMO_RULE_V1`은 이전 `main` 동작으로 동결한다.
2. **마감 전 참여 정정은 허용, 마감 후는 변경 불가.** `EVENT_ANNULLED`로 append-only 해시 체인을 깨지 않고 정정한다(설계만, 구현 전).
3. **마감 전 입찰 취소는 허용**, 마감 후는 불가(설계만, 구현 전).
4. **정정 승인자는 자산운용사·원장 운영자와 독립된 주체**여야 한다(설계 R14).
5. **독립 `requestParticipation`은 유지**한다(선점 위험 T-11은 잔여 위험으로 수용).
6. **PoC는 단일 원장 운영자**로 한다. 순번·시간 기준을 운영자가 정하며, 한계(운영자 신뢰, 순서·시간 조작, 키 탈취)는 설계 문서에 명시했다. 규정 요구가 아니라 PoC 단순화다.
7. **서명 스키마 v2·`blindingSalt`는 보류**하고 v1을 유지한다. 다이제스트 프라이버시 한계는 잔여 위험으로 둔다.
